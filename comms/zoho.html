Setup Instructions
To connect Zoho Social and Calendar:
  1. Go to api-console.zoho.eu
  2. Click + Add Client → choose Server-based Applications (NOT Self Client)
  3. Set Authorized Redirect URIs to exactly:
    https://aurelia.identitypartners.uk/comms/zoho.html
  4. Copy the new Client ID and Client Secret
  5. Go to Settings → Key Ingester → paste:
    Zoho_Client_ID=1000.XXXX
    Zoho_Client_Secret=XXXX
  6. Return here and click Connect Zoho Social
Why Server-based Application? Self Client doesn't support redirect URIs, which are required for the OAuth flow. Server-based Application allows Aurelia to receive the auth code after you approve access.
Your Zoho credentials: Configure Zoho_Client_ID and Zoho_Client_Secret in Settings → Key Ingester
