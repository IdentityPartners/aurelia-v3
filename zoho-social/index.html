Setup Instructions
Important: You need a Server-based Application (not Self Client) in the Zoho API Console. Self Client does not support redirect URIs.
  1. Go to api-console.zoho.com
  2. Click + Add Client → choose Server-based Applications
  3. Set Authorized Redirect URIs to:
    https://aurelia.identitypartners.uk/zoho-social/index.html
  4. Copy the new Client ID and Client Secret
  5. Go to Settings → Key Ingester → paste:
    Zoho_Client_ID=1000.XXXX
    Zoho_Client_Secret=XXXX
  6. Return here and click Connect Zoho Social
