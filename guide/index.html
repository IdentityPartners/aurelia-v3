Zoho Social — Direct Posting
Zoho Social supports direct posting AND scheduling. You do NOT need Google Calendar as a middleman. Connect once and post directly from Aurelia's Social Queue.
1
Create a Zoho Social app
Go to api-console.zoho.eu → Create Client → Self Client. Set redirect URI to: https://aurelia.identitypartners.uk/comms/zoho.html
2
Copy credentials
Copy your Client ID and Client Secret. Go to Settings → Key Ingester and paste:
Zoho_Client_ID=your_client_id
Zoho_Client_Secret=your_client_secret
3
Connect Zoho Social
Go to Comms → Zoho Integration and click "Connect Zoho Social". You'll be redirected to Zoho to authorise. After authorising, you'll return to Aurelia automatically.
4
Post directly
In Social Queue, click "Publish via Zoho" on any queued post. Zoho Social supports: LinkedIn, Facebook, Twitter/X, Instagram, Google My Business. This is direct posting, not just scheduling.
⚠ Zoho Social's free plan supports 1 brand and 7 channels. Paid plans add more brands and team members.
Zoho Calendar — No Google Calendar needed
Connect Zoho Calendar directly. You do NOT need Google Calendar as an intermediary.
1
Same app, different scope
Use the same Zoho app you created above. Go to Comms → Zoho Integration and click "Connect Zoho Calendar". This requests calendar-specific permissions.
2
Calendar appears on Home
Once connected, your Zoho Calendar events will appear in the Home page sidebar calendar widget and in the CRM for session scheduling.
Setmore — Booking Calendar
Setmore's free plan includes a booking page, email reminders, and basic integrations. No API key needed for the embed.
1
Get your Setmore booking URL
Log in to setmore.com → Settings → Booking Page → copy your booking URL (e.g. https://book.setmore.com/scheduleappointment/...)
2
Add to your profile
Go to My Profile → Personal → Booking Link. Paste your Setmore URL. This will appear in your platform bios and social posts.
3
Embed on identitypartners.uk
Add this to your website: <iframe src="YOUR_SETMORE_URL" width="100%" height="600" frameborder="0"></iframe>
For Setmore API access (to sync with Aurelia's CRM), you need Setmore Pro ($5/mo). The free embed works without an API key.
CRM Options — Zoho CRM, HubSpot & Others
Aurelia has a built-in CRM, but you can also integrate with external CRMs for bulk email and advanced features.
Zoho CRM (Free)
Free for 3 users. Includes contacts, deals, bulk email (2,000/day), and Zoho Social integration. Best if you're already using Zoho.
Zoho CRM ↗
HubSpot (Free)
Free CRM with unlimited contacts, email marketing (2,000/mo), and a good API. Best for bulk email campaigns.
HubSpot CRM ↗
Brevo (formerly Sendinblue)
Free: 300 emails/day, unlimited contacts. Best for transactional email and newsletters. Good API.
Brevo ↗
Mailchimp (Free)
Free: 500 contacts, 1,000 emails/mo. Good for newsletters and audience building. Integrates with most platforms.
Mailchimp ↗

Social Posting — Direct vs Scheduled
Clarifying what Zoho Social, Playwright, and the Social Queue each do.
Zoho Social
✓ Direct posting NOW
✓ Scheduled posting
✓ LinkedIn, Facebook, Twitter, Instagram, GMB
✗ TikTok, Bluesky, Telegram
Bluesky API
✓ Direct posting (free)
✓ No rate limits
✓ Already configured
Use: BLUESKY_HANDLE + BLUESKY_APP_PASSWORD
Playwright/Puppeteer
✓ Any platform
✓ Profile creation
✗ Slower, may break
✗ Requires Cloudflare Worker with browser
💡 For today's goal: Use Zoho Social for LinkedIn/Facebook/Twitter/Instagram + Bluesky API directly + Telegram API (already configured). This covers your main platforms without Playwright.
Chatbot for identitypartners.uk
Deploy an Aurelia-powered chatbot on your website. Visitors can ask about your services, book sessions, and get information.
1
Get the embed code
Go to Agenti City → select or create an agent → click "Deploy as Chatbot". Copy the embed code.
2
Add to identitypartners.uk
Paste this before </body> on your website:
<script src="https://aurelia.identitypartners.uk/chatbot/embed.js" data-agent="ip-default"></script>
3
Customise the chatbot
The chatbot uses your Identity Partners brand colours, knows about your services, and can direct visitors to your Setmore booking page.
The chatbot embed is being built. Go to Agenti City to configure your IP Default agent first.
