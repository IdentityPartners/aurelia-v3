Setup Instructions
Important: Use a Server-based Application in the Zoho API Console with redirect URI set to:
https://aurelia.identitypartners.uk/zoho-calendar/index.html
  1. Go to api-console.zoho.com
  2. Add Client → Server-based Applications
  3. Set redirect URI to: https://aurelia.identitypartners.uk/zoho-calendar/index.html
  4. Copy Client ID and Secret → Settings → Key Ingester
  5. Return here and click Connect
