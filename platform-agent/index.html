Method 2: Playwright / Puppeteer Headless Browser Semi-automated
For platforms that allow programmatic signup or profile creation. Playwright controls a real browser — it can fill forms, click buttons, upload images, and complete signups automatically.
Important: Playwright automation works best for platforms that don't have aggressive bot detection (Cloudflare, reCAPTCHA v3, SMS verification). For platforms with these, use direct signup instead. Always use a real email address and genuine profile information — never fake data.
1
Install Playwright on your Surface Pro or a VPS:
npm install playwright npx playwright install chromium
2
Basic signup script — adapt for each platform:
const { chromium } = require('playwright'); async function signupPlatform(url, email, password, profileData) { const browser = await chromium.launch({ headless: false }); // headless:false to see what's happening const page = await browser.newPage(); await page.goto(url); // Fill signup form (adapt selectors per platform) await page.fill('input[type="email"]', email); await page.fill('input[type="password"]', password); await page.fill('input[name="name"]', profileData.name); // Submit await page.click('button[type="submit"]'); await page.waitForNavigation(); // Fill profile await page.fill('textarea[name="bio"]', profileData.bio); await page.click('button:has-text("Save")'); await browser.close(); } // Run for each platform signupPlatform('https://www.fiverr.com/join', 'simon@identitypartners.uk', 'YourPassword123!', { name: 'SJ Johnson', bio: 'Professional listening and identity coaching...' } );

For platforms with public APIs. Once your profile is created, use these APIs to post content automatically from Aurelia's Social Queue.

End-to-end workflow: Text to 196 platforms
The complete pipeline from raw content to posted assets across all platforms.
1
Write or paste content — blog post, essay, transcript, research notes. 500–5000 words works best.
2
Go to Atomise — paste content, select asset types (quotes, insights, tips, questions, CTAs, carousels), select platforms, set count to 250–500, click Atomise.
3
Review and edit — scan the generated assets, edit any that need tweaking, delete weak ones. Click "Queue All" to send everything to Social Queue.
4
Go to Social Queue — review queued posts, set schedules, click Publish All. Bluesky and Telegram post immediately. Zoho Social handles LinkedIn/Facebook/Twitter/Instagram.
5
For platforms without API (Fiverr, Bark, Substack, etc.) — use the Platform Agent to generate Playwright scripts, or copy-paste from the queue manually. These platforms drive inbound leads, not outbound posts.
6
Track results — mark platforms as Active in Platform Manager, note which content types perform best, feed learnings back into your next atomisation run.
Realistic timeline:
Week 1: Set up Tier 1 platforms manually (Fiverr, Bark, Premium.Chat, Topmate, Substack, Ko-fi, Paperbell) — 2-3 hours
Week 2: Atomise your first body of content, post to Bluesky/Telegram/Zoho Social — 30 minutes
Week 3: Set up Tier 2 platforms (Circle, Mighty Networks, Gumroad, Payhip) — 2 hours
Ongoing: Weekly atomisation run, 250 assets, scheduled posting — 20 minutes/week
